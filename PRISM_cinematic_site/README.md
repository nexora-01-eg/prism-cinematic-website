# PRISM / 02

Second cinematic concept: **Light as Interface**.

A different visual direction from NOVA:
- refractive glass-like 3D prism
- chromatic light rings
- particle atmosphere
- cursor-reactive camera
- scroll-reactive depth
- cinematic bloom
- oversized editorial typography
- responsive layout

Open `index.html` directly or use VS Code Live Server.
Internet is required at runtime for Three.js modules from jsDelivr.
